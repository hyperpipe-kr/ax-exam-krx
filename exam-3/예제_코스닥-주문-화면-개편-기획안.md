## 요약

주문 화면이 호가를 보내기 전에 입력값을 먼저 검사하도록 바꾼다. 지금은 주문 서버가 검사한다. 사용자는 호가를 제출한 뒤에야 거부 사유를 본다.

이 기획안은 화면에 넣을 검증 규칙 16개(R-01~R-16)를 정의한다. 규칙은 다섯 영역으로 나눈다.

- 필수 입력 항목 6개
- 스톱지정가호가 4개
- 호가가격단위와 호가수량 2개
- 호가접수시간과 시장 구분 2개
- 정정·취소 2개

**검수 요청:** 각 규칙이 시행세칙과 맞는지 검수해 주기 바란다. 규칙이 시행세칙보다 느슨하면 위반 호가가 화면을 통과한다. 규칙이 더 엄격하면 정상 호가가 막힌다. 두 방향을 모두 확인해 주기 바란다.

## 1. 추진 배경

현재 주문 화면은 입력값을 거의 검사하지 않고 주문 서버로 넘긴다. 예를 들어 사용자가 호가가격단위와 맞지 않는 가격을 넣으면, 제출 후 주문 서버가 거부 메시지를 돌려보낸다. 사용자는 거부 사유를 확인하고 처음부터 다시 입력해야 한다.

개편안은 두 가지를 바꾼다.

1. 주문 서버가 하던 입력값 검사를 화면으로 옮긴다. 사용자는 제출하기 전에 오류를 보고 그 자리에서 고친다.
2. 스톱지정가호가 입력 화면과 장종료후 시간외시장(시간외종가매매·시간외접속매매) 입력 화면을 새로 만든다.

화면이 검사를 맡으면 규칙이 틀렸을 때의 영향도 화면에서 바로 나타난다. 규칙을 개발 전에 시행세칙과 대조하려는 이유다.

## 2. 목표와 범위

**목표**

- 시행세칙에 맞지 않는 호가를 화면에서 걸러 제출 전에 알린다.
- 시행세칙이 허용하는 호가는 화면에서 막지 않는다.
- 사용자가 거부 사유와 고칠 방법을 화면에서 바로 확인한다.

**범위**

| 포함 | 제외 |
|---|---|
| 정규시장 신규·정정·취소 호가 입력 화면 | 거래소 시스템의 접수·체결 처리 |
| 스톱지정가호가 입력 화면 (신설) | 대량매매·바스켓매매·경쟁대량매매 화면 |
| 장종료후 시간외시장 입력 화면 (신설) | 회원사 내부 위험관리 한도 |
| 화면 오류 메시지와 입력란 활성·비활성 | 주문 서버 내부 로직 변경 |

## 3. 화면 구성

| 화면 | 주요 입력란 | 신설 여부 |
|---|---|---|
| 일반 주문 | 종목코드, 매도·매수, 호가 유형, 가격, 수량, 계좌, 매도 호가 구분 | 개편 |
| 스톱지정가 주문 | 일반 주문 입력란 + 스톱가격 | 신설 |
| 시간외 주문 | 시장 구분(시간외종가매매·시간외접속매매), 호가 유형, 가격, 수량 | 신설 |
| 정정·취소 | 원주문번호, 정정 가격, 정정·취소 수량 | 개편 |

화면은 입력값을 세 가지로 처리한다.

- **허용:** 그대로 제출한다.
- **거부:** 제출 버튼을 막고 오류 메시지를 표시한다.
- **비활성화:** 해당 입력란이나 선택지를 아예 표시하지 않거나 누를 수 없게 한다.

## 4. 입력 검증 규칙

규칙의 예시는 부록의 가상 종목을 사용한다.

| 규칙 | 영역 | 요약 | 화면 동작 |
|---|---|---|---|
| R-01 | 필수 입력 | 시장가·최유리지정가·최우선지정가호가는 가격 없이 제출 | 가격 입력란 비활성화 |
| R-02 | 필수 입력 | 취소 호가는 새 주문번호만 필수, 원주문번호는 선택 | 원주문번호 없어도 허용 |
| R-03 | 필수 입력 | 모든 호가는 가격 필수 | 가격이 비면 거부 |
| R-04 | 필수 입력 | 수량은 화면 검증에서 제외 | 검사하지 않음 |
| R-05 | 필수 입력 | 스톱가격은 선택 입력 | 비어도 허용 |
| R-06 | 필수 입력 | 차입공매도는 공매도 등록번호 필수 | 비면 예외 없이 거부 |
| R-07 | 스톱지정가 | 매수: 직전 체결가격 > 스톱가격일 때 발동 | 같으면 대기 |
| R-08 | 스톱지정가 | 매도: 직전 체결가격 ≤ 스톱가격일 때 발동 | 조건 충족 시 지정가호가로 전환 |
| R-09 | 스톱지정가 | 당일 체결이 없으면 스톱지정가호가 거부 | 거부 |
| R-10 | 스톱지정가 | 스톱가격은 호가가격단위 검사 제외 | 검사하지 않음 |
| R-11 | 가격·수량 | 가격대별 호가가격단위 검사 | 단위 불일치 시 거부 |
| R-12 | 가격·수량 | 시가총액 구간별 1회 호가수량 한도 | 초과 시 거부 |
| R-13 | 시간·시장 | 시장별 호가접수시간 | 시간 밖이면 거부 |
| R-14 | 시간·시장 | 시간외접속매매에서 시장가·조건부지정가·중간가·스톱지정가호가 제외 | 선택지 비활성화 |
| R-15 | 정정·취소 | 전량 체결된 호가는 취소 불가 | 취소 버튼 비활성화 |
| R-16 | 정정·취소 | 같은 가격으로 수량만 줄이는 정정 허용 | 허용 |

### 4.1 필수 입력 항목

#### R-01. 가격 없이 제출하는 호가 유형

- **규칙:** 시장가호가, 최유리지정가호가, 최우선지정가호가를 고르면 가격 입력란을 비활성화한다. 가격 필드는 비워서 전송한다.
- **예시:** 종목 A 시장가 매수 100주 → 가격 없이 제출을 허용한다.
- **기획 근거:** 시행세칙 제7조제1항제12호

#### R-02. 취소 호가의 주문번호

- **규칙:** 취소 호가는 새 주문번호만 필수로 검사한다. 원주문번호는 선택 입력으로 둔다. 사용자가 주문 목록에서 취소 대상을 고르지 않고 직접 입력하는 경우가 많아, 원주문번호를 필수로 두면 입력 오류가 늘어난다.
- **예시:** 원주문번호를 비우고 새 주문번호 0000131만 넣은 취소 호가 → 허용한다.
- **기획 근거:** 시행세칙 제7조제1항제6호

#### R-03. 가격 필수 검사

- **규칙:** R-01의 세 유형을 제외한 모든 호가는 가격을 필수로 검사한다. 정정·취소 화면에서도 같은 검사를 적용한다. 가격이 비면 ‘가격 누락’ 오류로 제출을 막는다.
- **예시:** 종목 A 지정가 매도호가(주문번호 0000140)를 전량 취소하면서 가격을 비움 → ‘가격 누락’으로 거부한다.
- **기획 근거:** 시행세칙 제7조제1항제12호 본문

#### R-04. 수량 검증 제외

- **규칙:** 수량은 화면 검증 대상에서 뺀다. 주문 서버가 계좌의 기본 주문 수량을 자동으로 채운다고 가정한다. 접수 결과 화면에서도 공간을 확보하려고 수량 열을 표시하지 않는다.
- **예시:** 수량을 비운 지정가 매수호가 12,000원 → 화면은 그대로 제출한다.
- **기획 근거:** 주문 서버 연계 사양서 (별도 문서, 이 기획안에 첨부하지 않음)

#### R-05. 스톱가격 선택 입력

- **규칙:** 스톱지정가 주문 화면에서 스톱가격은 선택 입력으로 둔다. 지정가격이 들어 있으면 스톱가격을 비워도 제출한다.
- **예시:** 종목 A 매수 스톱지정가호가, 지정가격 10,050원, 수량 50주, 스톱가격 공란 → 허용한다.
- **기획 근거:** 시행세칙 제7조제1항제12호

#### R-06. 차입공매도의 공매도 등록번호

- **규칙:** 매도 호가 구분이 ‘차입공매도’이면 공매도 등록번호를 필수로 검사한다. 번호가 비면 예외 없이 거부한다. 위탁자나 회원의 등록번호 발급 정보는 화면이 조회하지 않는다.
- **예시:** 종목 C 차입공매도 지정가 21,500원, 30주, 등록번호 공란 → 거부한다.
- **기획 근거:** 시행세칙 제7조제1항제24호의3

### 4.2 스톱지정가호가

#### R-07. 매수 스톱지정가호가의 발동 조건

- **규칙:** 직전 체결가격이 스톱가격보다 **높을 때만** 지정가호가로 효력을 발생시킨다. 두 가격이 같으면 대기한다.
- **예시:** 종목 A 직전 체결가격 10,000원, 매수 스톱가격 10,000원 → 대기한다.
- **기획 근거:** 시행세칙 제2조제5항제2호

#### R-08. 매도 스톱지정가호가의 발동 조건

- **규칙:** 직전 체결가격이 스톱가격과 같거나 낮으면 지정가호가로 효력을 발생시킨다. 화면은 발동만 표시하며 체결 여부는 표시하지 않는다.
- **예시:** 종목 A 직전 체결가격 9,990원, 매도 스톱가격 10,000원 → 효력을 발생시킨다.
- **기획 근거:** 시행세칙 제2조제5항제1호

#### R-09. 당일 체결이 없는 종목

- **규칙:** 당일 체결이 한 건도 없으면 비교할 직전 체결가격이 없다. 이때는 ‘직전 체결가격 없음’ 오류로 스톱지정가호가를 거부한다.
- **예시:** 종목 B(당일 체결 없음, 기준가격 10,000원), 매수 스톱가격 9,990원 → 거부한다.
- **기획 근거:** 시행세칙 제2조제5항제2호

#### R-10. 스톱가격의 호가가격단위

- **규칙:** 스톱가격은 발동 기준일 뿐 체결 가격이 아니다. 따라서 스톱가격은 호가가격단위를 검사하지 않는다. 지정가격만 R-11로 검사한다.
- **예시:** 종목 A 매도 스톱가격 9,995원, 지정가격 9,980원 → 허용한다.
- **기획 근거:** 기획 담당자 의견 (규정 근거 미기재)

### 4.3 호가가격단위와 호가수량

#### R-11. 호가가격단위

- **규칙:** 지정가격이 아래 표의 단위와 맞지 않으면 ‘호가가격단위 오류’로 거부한다.

| 1주의 가격 | 호가가격단위 |
|---|---:|
| 2,000원 미만 | 1원 |
| 2,000원 이상 5,000원 미만 | 5원 |
| 5,000원 이상 20,000원 미만 | 10원 |
| 20,000원 이상 50,000원 미만 | 100원 |
| 50,000원 이상 200,000원 미만 | 100원 |
| 200,000원 이상 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

- **예시:** 종목 C 지정가 매수 20,050원 → 거부한다.
- **기획 근거:** 주문시스템 내부 호가단위표 (2019년 작성)

#### R-12. 1회 호가수량 한도

- **규칙:** 아래 한도를 넘는 수량은 ‘호가수량 한도 초과’로 거부한다. 위탁 주문이면 한도 안으로 나누어 다시 입력하라고 안내한다. 대량매매·바스켓매매·경쟁대량매매 호가는 이 화면의 범위가 아니다.

| 해당거래일 시가총액 | 1회 호가수량 한도 |
|---|---|
| 10조원 이상 | 1,000억원 ÷ 해당거래일 기준가격 |
| 1,000억원 이상 10조원 미만 | 상장증권수의 100분의 1 |
| 200억원 이상 1,000억원 미만 | 10억원 ÷ 해당거래일 기준가격 |
| 200억원 미만 | 상장증권수의 100분의 5 |

- **예시:** 종목 D(시가총액 500억원, 기준가격 5,000원)의 한도는 10억원 ÷ 5,000원 = 200,000주다. 250,000주 매수 → 거부하고 분할 입력을 안내한다.
- **기획 근거:** 시행세칙 제8조제4항·제5항

### 4.4 호가접수시간과 시장 구분

#### R-13. 시장별 호가접수시간

- **규칙:** 시간외 주문 화면은 아래 시간에만 제출을 허용한다. 시각은 서버 시각(KST)으로 판단한다.

| 시장 구분 | 접수 시간 |
|---|---|
| 장개시전 시간외종가매매 | 8시 30분 ~ 8시 40분 |
| 장종료후 시간외종가매매 | 장종료후 ~ 16시 30분 |
| 장종료후 시간외접속매매 | 16시 ~ 20시 |

- **예시:** 16시 05분에 제출한 장종료후 시간외종가매매 매수호가 → 허용한다.
- **기획 근거:** 주문 업무 매뉴얼 2025년판 4.2절

#### R-14. 시간외접속매매의 호가 유형

- **규칙:** 시간외접속매매를 고르면 호가 유형에서 시장가호가, 조건부지정가호가, 중간가호가, 스톱지정가호가를 비활성화한다.
- **예시:** 17시 10분 시간외접속매매 화면 → 시장가·중간가·스톱지정가 선택지가 보이지 않는다.
- **기획 근거:** 시행세칙 제8조

### 4.5 정정·취소

#### R-15. 전량 체결된 호가의 취소

- **규칙:** 주문 목록에서 전량 체결된 호가는 취소 버튼을 비활성화한다.
- **예시:** 10,000원, 100주 지정가 매도호가가 100주 모두 체결됨 → 취소 버튼을 누를 수 없다.
- **기획 근거:** 시행세칙 제18조의2제2항

#### R-16. 같은 가격으로 수량만 줄이는 정정

- **규칙:** 지정가호가를 같은 가격의 지정가호가로 정정하면서 수량만 줄이는 요청을 허용한다. 사용자는 취소 화면으로 가지 않고 정정 화면에서 수량을 바로 줄인다.
- **예시:** 지정가 매수 10,000원, 100주 → 같은 가격 10,000원, 50주로 정정 → 허용한다.
- **기획 근거:** 시행세칙 제18조의2제3항
