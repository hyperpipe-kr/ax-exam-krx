# 업무규정 검토 에이전트 — 기획안 검수

시행세칙을 지식 자료로 등록한 에이전트로 가상의 주문 화면 개편 기획안을 검수한다. 기획안의 규칙이 시행세칙과 맞는지, 추가로 확인할 자료가 무엇인지 근거와 함께 정리한다.

## 준비

- **지식 자료:** 「코스닥시장 업무규정 시행세칙」 PDF(63쪽). 첫 페이지에 ‘일부개정 2026. 9. 10., 규정 제2500호, 시행 2026. 9. 14.’로 표기된 판본을 쓴다.
- **검수 대상:** `예제_코스닥-주문-화면-개편-기획안.pdf`. 교육용 가상 기획안이며, 검수할 입력 규칙은 R-01~R-16이다.
- **도구:** 기관에서 승인한 도구·계정만 사용한다. 실제 내부 파일·개인정보·미공개 정보를 추가하지 않는다. 이 실습은 배포한 판본과 기획안을 대조하는 연습이다. 실제 시스템의 적법성을 판단하지 않는다.

## 1. 에이전트 만들기

시행세칙 PDF만 지식 자료로 등록한다. 에이전트가 이 PDF를 근거로 답하고, PDF에서 확인하지 못한 내용은 추정하지 않도록 지침을 적는다.

## 2. 기획안 검수 프롬프트

만든 에이전트에서 새 대화를 열고 기획안 PDF만 첨부한 뒤 아래 프롬프트를 입력한다.

> 에이전트를 사용하여 첨부한 기획안의 입력 검증 규칙 R-01~R-16을 검수해 주세요. 규칙마다 ‘적합 / 수정 필요 / 확인 필요’ 중 하나로 판정해 주세요. 규칙이 시행세칙보다 느슨해 위반 호가가 통과하는지, 더 엄격해 정상 호가가 막히는지도 구별해 주세요. 번호별로 근거 조·항·호와 PDF 쪽수, 판정 이유, 고친 규칙 문장이나 추가로 필요한 자료를 표에 적어 주세요. PDF 첫 장을 1쪽으로 세어 주세요. 기획안이 인용한 조항과 내부 자료가 맞는지도 확인해 주세요. PDF에서 확인되지 않는 내용은 추정하지 말아 주세요. 마지막에는 16개 규칙의 일괄 확정 요청을 받아들일 수 있는지 한 문장으로 정리해 주세요.

## 3. 결과 확인

규칙 16개가 빠짐없이 나왔는지 확인한다. 답변에 적힌 조·항·호와 PDF 쪽수를 원문과 대조한다. 근거가 없으면 판정을 확정하지 않고 필요한 자료를 적는다.
