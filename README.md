# KRX AX 강의 실습 예제

한국거래소 신입직원이 AI로 실무 문서를 다루는 실습 4개다. 데이터를 정리하고, 규정과 대조하고, 보고서 디자인을 재사용하는 순서로 난도를 높인다. 각 실습은 단계별 프롬프트로 결과를 확인한 뒤, 같은 처리를 반복해서 쓸 수 있게 스킬이나 에이전트로 만드는 것으로 끝난다.

**자료의 성격**

- exam-1·2의 기업·시세·공시·접수·기한은 모두 교육용 가상 값이다.
- exam-3의 시행세칙은 실제 규정 PDF이고, 기획안은 가상 문서다. 기획안에는 시행세칙과 맞지 않는 규칙을 일부러 넣었다.
- exam-4의 업무보고는 실제 공개 자료다. 디자인만 추출하고, 수치·정책 문구·로고·사진은 새 PPT에 옮기지 않는다.

## 공통 원칙

모든 실습의 프롬프트에 같은 원칙이 들어 있다. 학생이 결과를 볼 때도 이 기준으로 확인한다.

- **원본 보존:** 원본 파일은 바꾸지 않고 결과를 새 파일로 저장한다.
- **추정 금지:** 결측값이나 자료에 없는 사실을 채우지 않고 제한사항이나 확인 필요로 표시한다.
- **근거 표시:** 원본행ID, 조·항·호와 쪽수, 원본 페이지처럼 결과의 출처를 함께 적는다.
- **정직한 보고:** 실행하지 못한 계산·렌더링·시험은 실행했다고 쓰지 않는다.
- **승인 도구:** 기관에서 승인한 도구·계정만 쓰고 실제 내부 파일·개인정보·미공개 정보를 섞지 않는다.

## 가장 먼저 할 일

수업 전에 KRX 웍스AI 계정에서 실습별로 아래를 확인한다. 직접 실습 환경이 없으면 같은 흐름을 강사 시연으로 운영한다.

1. **exam-1:** 시장 파일을 올리고 프롬프트를 순서대로 실행한다. 확인 대상 6건이 나오는지 강사용 정답과 대조하고, 계산과 결과 다운로드가 되는지 확인한다.
2. **exam-2:** 접수 파일을 올리고 기한 판정까지 실행한다. 판정 결과를 강사용 정답과 대조한다.
3. **exam-3:** 시행세칙 PDF를 지식 자료로 등록해 에이전트를 만들 수 있는지 확인한다. 기획안만 첨부해 실행하고, 판정 16건을 검수표와 대조한다.
4. **exam-4:** 업무보고 PDF의 페이지를 이미지로 읽는지 확인한다. 읽지 못하면 `page-images`의 PNG 12장을 쓴다. 등록한 스킬로 연구보고서 장표를 만들고 PPTX를 내려받을 수 있는지 확인한다. PPTX 생성이 안 되면 디자인 명세와 장별 설계안까지만 진행한다.
5. **스킬 등록:** 웍스AI가 스킬을 지원하는지 확인한다. 지원하지 않으면 스킬 본문을 에이전트 지침으로 붙여 쓰는 방식으로 바꾼다.
