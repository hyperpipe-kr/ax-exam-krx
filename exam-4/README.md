# 업무보고의 슬라이드 디자인을 추출해 PPT 만들기

업무보고에서 색·글꼴·레이아웃을 추출해 재사용할 디자인 명세로 정리한다. 이 명세와 작업 순서를 스킬로 등록한 뒤, 스킬을 사용해 예제 연구보고서를 같은 스타일의 PPT로 만든다.

디자인 컴포넌트는 장표에서 반복되는 부품이다. 예를 들어 이 보고서의 모든 본문 장은 맨 위에 같은 파란 그라데이션 띠를 두고 그 위에 흰 제목을 쓴다. 이 띠가 하나의 컴포넌트다. 부품의 색·크기·위치를 숫자로 적어 두면, 사람이 바뀌어도 같은 모양의 장표를 다시 만든다.

## 준비

- **원본:** 2026_금융위-업무보고_한국거래소.pdf. 12장, 16:9(960 × 540pt), PowerPoint 2019에서 내보낸 PDF다.
- **PNG 대체 자료:** `page-images` 폴더에 업무보고 1~12장의 PNG(각 2000 × 1125 px)가 있다. 도구가 PDF 페이지를 이미지로 읽지 못하면 PNG 12장을 페이지 순서대로 첨부한다.
- **예제 원고:** 연구보고서_코스피-200-월물옵션과-위클리옵션의-양적-질적-분석-및-시사점.pdf. 4단계에서 사용한다.
- **도구:** 기관에서 승인한 도구·계정만 사용한다. 파일 업로드, 이미지 판독, 스킬 등록, PPTX 생성·다운로드가 가능한지 미리 확인한다. PPTX를 만들 수 없으면 디자인 명세와 장별 설계안까지만 진행한다.
- **권리:** 원본의 한국거래소 로고, 현장 사진, 아이콘 그림은 추출 대상이 아니다. 새 PPT에는 자리만 비워 두고, 사용 권한을 확인한 파일만 넣는다. 새 PPT를 한국거래소의 공식 보고서처럼 표시하지 않는다.
- **주의:** 업무보고 PDF의 2~11장은 글자 대부분이 그림으로 들어 있다. 텍스트만 추출하면 글자 배치나 도식이 빠진다. 에이전트가 **페이지 이미지를 보고** 분석하는지 확인한다.

## 실습 흐름

| 단계 | 하는 일 | 산출물 |
|---|---|---|
| 1 | 원본에서 디자인 요소 추출 | 색·글꼴·레이아웃 분석 |
| 2 | 다시 쓸 수 있는 명세로 정리 | 디자인 토큰(JSON), 컴포넌트 표 |
| 3 | 디자인 명세와 작업 순서를 스킬로 등록 | `krx-report-slide` 스킬 |
| 4 | 스킬로 연구보고서 장표를 만들고 원문과 대조 | 장별 설계안, PPTX(8장 안팎), 수치·결론 대조표 |

아래 프롬프트는 한 번에 붙이지 말고 단계별 결과를 확인한 뒤 다음으로 넘어간다.

## 1. 디자인 요소 추출

입력 자료에 맞는 프롬프트 하나를 사용한다.

### PDF 파일 대상

> 첨부한 PDF는 16:9 보고서입니다. 내용이 아니라 디자인을 분석해 주세요. 여러 장의 글자가 그림으로 들어 있으니 텍스트 추출 결과만으로 판단하지 말고 페이지 이미지를 보고 분석해 주세요. 다음 다섯 가지를 정리해 주세요. ① 슬라이드 크기와 여백 ② 색: 배경, 제목 띠, 제목 글자, 강조 글자, 표, 섹션별 색과 HEX 값 ③ 글꼴과 크기 위계: 제목, 소제목, 본문, 주석 ④ 여러 장에 반복되는 레이아웃 컴포넌트와 각각이 나오는 페이지 번호 ⑤ 로고·사진·아이콘의 위치와 역할. 측정한 값과 눈으로 추정한 값을 구분해 표시해 주세요. 로고·사진·아이콘은 복제하지 말고 위치와 역할만 기록해 주세요.

### PNG 파일 대상

> 첨부한 PNG에서 보고서 내용이 아니라 디자인을 분석해 주세요. 먼저 파일명 끝의 번호를 보고 1~12장이 모두 있는지 확인해 주세요. 다음 다섯 가지를 정리해 주세요. ① 이미지 크기·가로세로 비율과 여백: 크기와 여백은 px로, 주요 요소의 위치는 이미지 너비·높이 대비 비율로 표시해 주세요. ② 색: 배경, 제목 띠, 제목 글자, 강조 글자, 표, 섹션별 색과 HEX 값 ③ 글자의 시각적 위계: 제목, 소제목, 본문, 주석의 상대 크기와 굵기 ④ 반복되는 레이아웃과 해당 페이지 번호: 표(7·8장), 지적사항 흐름(10·11장), 마무리(12장)도 확인해 주세요. ⑤ 로고·사진·아이콘의 위치와 역할. 측정값과 추정값을 구분하고, PNG만으로 확인할 수 없는 원본 크기(pt)·글꼴 이름·글자 크기(pt)는 확정하지 말아 주세요. 빠진 페이지의 디자인은 추정하지 말고 확인하지 못했다고 표시해 주세요. 로고·사진·아이콘은 복제하지 말아 주세요.


## 2. 다시 쓸 수 있는 명세로 정리

> 앞의 분석을 다른 PPT에 쓸 수 있는 디자인 명세로 정리해 주세요. 색·글꼴·글자 크기·주요 요소의 좌표(인치)는 JSON으로 써 주세요. PNG로 분석했다면 이미지 너비·높이 대비 좌표 비율을 목표 슬라이드 크기(이 실습에서는 원본 PDF와 같은 960 × 540pt)에 적용해 인치로 환산해 주세요. PNG로 확인하지 못한 글꼴과 글자 크기를 새 PPT에 제안할 때는 원본 측정값과 구분해 주세요. 컴포넌트는 이름, 용도, 구성 요소, 원본 페이지, 쓰지 말아야 할 경우를 표로 써 주세요. 섹션마다 색을 바꾸는 규칙처럼 여러 장에 걸친 규칙도 따로 적어 주세요.


## 3. 스킬로 등록하기

스킬은 디자인 명세와 작업 순서를 폴더 하나에 묶어 둔 것이다. 스킬을 등록하면 다음부터 "KRX 업무보고 스타일로 장표 만들어 줘" 한 문장으로 같은 순서와 같은 값을 적용한다.


> 지금까지 정리한 디자인 명세와 작업 순서를 스킬로 만들어 주세요. 스킬 이름은 krx-report-slide로 하고 본문에는 요청 파악 → 구성 설계 → 빌드 → 렌더링 검수 → 전달 순서와 디자인 원칙, 로고·사진의 권리 표기를 넣어 주세요. 로고·사진 파일은 폴더에 넣지 말아 주세요.


## 4. 스킬 사용하기

등록한 스킬로 다른 문서를 업무보고 스타일의 장표로 바꾼다. 예제 원고는 「코스피200 월물옵션과 위클리옵션의 양적·질적 분석 및 시사점」 연구보고서다. A4 세로 37쪽이고, 첫 쪽에 연구 목적·핵심 결론·정책 방향·총평을 요약해 두었다. 본문은 Ⅰ 연구배경, Ⅱ 거래증감 분해, Ⅲ 경로별 투자자 특성, Ⅳ 시장품질 점검, Ⅴ 결론 및 시사점으로 나뉜다.

원고를 장표로 옮길 때 가장 흔한 실수는 수치가 바뀌거나 결론이 과장되는 것이다. 한 번에 만들지 말고 설계 → 생성 → 수치 대조 순서로 나눠 진행한다.

### 단계 A. 장별 설계안

> krx-report-slide 스킬로 첨부한 연구보고서를 8장 안팎의 보고용 장표로 만들려고 합니다. 먼저 PPTX를 만들지 말고 장별 설계안만 표로 보여 주세요. 표에는 장 번호, 제목, 핵심 메시지 한 줄, 사용할 컴포넌트, 들어갈 수치, 원문 쪽수를 넣어 주세요. 구성은 표지 → 요약(연구 목적·핵심 결론·정책 방향) → 연구 배경 → 분석 방향(세 기둥: 거래증감 분해, 경로별 투자자 특성, 시장품질 점검) → 섹션별 핵심 결과 → 정책 방향 → 마무리를 기본으로 해 주세요. 세 기둥의 색은 해당 섹션 장까지 그대로 이어 주세요. 수치는 보고서 본문과 표에 적힌 값만 쓰고, 그래프를 눈으로 읽어 값을 만들지 말아 주세요.

설계안을 보고 장 순서나 컴포넌트를 고친 뒤 다음 단계로 넘어간다.

### 단계 B. PPTX 생성

> 위 설계안으로 PPTX를 만들어 주세요. 표지에는 보고서 제목과 작성 부서를 쓰고, 아래에 '연구보고서 요약 — 교육용'이라고 표시해 주세요. 핵심 메시지 줄에서는 핵심어 한두 개만 주황으로 강조해 주세요. 정책 방향 장은 분석 결과와 정책 대응을 짝지은 흐름으로, 거래증감 경로별 비중은 표로 만들어 주세요. 보고서에 없는 해석·전망·수치는 넣지 말아 주세요. 장마다 발표자 노트에 사용한 컴포넌트와 원문 쪽수를 적어 주세요. 로고는 넣지 말고 자리만 남겨 주세요.

### 단계 C. 수치·결론 대조

> 만든 PPTX의 모든 수치와 결론 문장을 원문과 대조해 표로 정리해 주세요. 표에는 장 번호, 장표의 문장이나 수치, 원문 쪽수와 원문 표현, 일치 여부를 넣어 주세요. 단위(%, 조원, 억원)와 기간(분기 평균, 연평균)이 원문과 같은지 확인해 주세요. 원문이 '증거가 제한적'처럼 유보한 내용을 장표에서 단정했는지도 확인해 주세요. 맞지 않는 항목은 고친 뒤 다시 렌더링해 확인해 주세요. 렌더링을 실행할 수 없으면 실행하지 못했다고 말해 주세요.

### 수정 요청 예시

결과를 보고 필요한 것만 골라 요청한다.

> 4장은 글이 많아 두 장으로 나눠 주세요. 글자 크기를 줄여서 해결하지 말아 주세요.

> 경로별 비중 표를 막대 차트로 바꿔 주세요. 값은 지금 표의 숫자를 그대로 쓰고, 축은 0%에서 시작해 주세요. 차트는 편집할 수 있는 PowerPoint 차트로 만들어 주세요.

> 같은 내용을 임원 보고용 3장(요약, 핵심 결과, 정책 방향)으로 줄인 판도 만들어 주세요. 8장 판은 그대로 두고 새 파일로 저장해 주세요.

### 확인 기준

- 스킬이 실제로 쓰였다. 업무보고 스타일의 제목 띠, 기둥 색, 컴포넌트가 적용됐다.
- 장표의 수치가 원문의 값·단위·기간과 같고, 발표자 노트에 원문 쪽수가 있다.
- 원문이 유보한 결론을 단정하지 않았다. 예를 들어 "위클리가 월물을 잠식하지 않는다"처럼 쓰지 않는다.
- 업무보고 원본의 수치·정책 문구가 섞이지 않았다.
- 그래프에서 눈으로 읽은 값을 만들어 넣지 않았다.
